**No Priors — Building an AI Guardian for Enterprise with Onyx Security CEO Maxim Bar Kogan**

**The Takeaway:** As AI agents become more autonomous and widely deployed, enterprises need a new category of security — an independent "guardian" system that watches the agents, using specialized small models to decide when to escalate for deeper inspection, rather than relying on the same labs that build the agents.

**The Takeaway:** 随着 AI agent 变得越来越自主且广泛部署，企业需要一种全新的安全类别——一个独立的"守护者"系统来监视这些 agent，使用专门的轻量模型来判断何时需要升级进行深入检查，而不是依赖构建这些 agent 的同一批实验室。

Maxim Bar Kogan, co-founder and CEO of Onyx Security, is building an AI security company from Tel Aviv with a thesis that most enterprises are only beginning to grasp: the agents you're deploying to boost productivity are also creating an exponentially growing attack surface that existing security tools cannot handle. Onyx trains specialized models to oversee other AI agents — not by running another full-scale LLM alongside every agent (that would be prohibitively expensive and slow), but by training very small, focused models that can quickly flag suspicious actions and decide when to call in a smarter agent for deeper inspection.

Maxim Bar Kogan，Onyx Security 的联合创始人兼 CEO，正在特拉维夫打造一家 AI 安全公司。他的核心观点是大多数企业才刚刚开始意识到：你为提高生产力而部署的 agent，同时也在创造一个指数级增长的攻击面，而现有的安全工具无法应对。Onyx 训练专门的模型来监视其他 AI agent——不是在每个 agent 旁边运行另一个全尺寸 LLM（那样成本太高、速度太慢），而是训练非常小、非常专注的模型，快速标记可疑行为，并决定何时需要调用更聪明的 agent 进行深入检查。

The analogy Kogan draws is blitz chess: most moves are intuitive, made without deep calculation, based on pattern recognition from thousands of games. Only at critical junctures does a grandmaster pause to calculate deeply. Onyx's system works the same way — most agent actions pass through without scrutiny, but when something looks off, the system escalates.

Kogan 用快棋来类比：大多数走法都是直觉性的，不需要深度计算，而是基于对数千盘棋的模式识别。只有在关键时刻，大师才会停下来深入计算。Onyx 的系统也是如此——大多数 agent 的行为无需审查即可通过，但当某些行为看起来不对劲时，系统就会升级处理。

A key insight: enterprises are not willing to give Anthropic or OpenAI access to their historical agent behavior data, because they know these companies want to train on it. But they are willing to give that data to an independent security vendor. This structural advantage, Kogan argues, makes it unlikely that the large labs can fully solve the agent security problem themselves.

一个关键洞察：企业不愿意让 Anthropic 或 OpenAI 访问他们的历史 agent 行为数据，因为他们知道这些公司想用这些数据来训练。但他们愿意将这些数据交给一个独立的安全供应商。Kogan 认为，这种结构性优势使得大型实验室不太可能完全自己解决 agent 安全问题。

Kogan also addresses the Mythos-level vulnerability finding threat — the plummeting cost of finding security vulnerabilities using AI coding tools. His advice: invest in foundational security controls now, because these models are coming regardless of anyone's phased rollout plans.

Kogan 还谈到了 Mythos 级别的漏洞发现威胁——使用 AI 编码工具发现安全漏洞的成本正在急剧下降。他的建议是：现在就投资于基础安全控制，因为无论任何人如何分阶段推出，这些模型都一定会到来。

> "If you're not building some kind of controls that are built for these systems, then you're either going to end up limiting them a lot, making them almost much less useful to the enterprise, or you're going to miss a lot of pretty dangerous things that they might be doing."

> "如果你不为这些系统构建某种专门的控制机制，那么你要么会极大地限制它们，让它们对企业几乎失去价值，要么会错过它们可能做的很多相当危险的事情。"
