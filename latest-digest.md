### No Priors: Building an AI Guardian for Enterprise with Onyx Security CEO Maxim Bar Kogan

**The Takeaway:** 随着 AI agent 在企业中自主执行的任务呈指数级增长，传统的安全工具（身份管理、端点保护、API 安全）已经完全失效——你需要一个专门训练的小模型作为"守护者"，在关键时刻介入，而不是用一个大模型去监控另一个大模型。

Onyx Security 的 CEO Maxim Bar Kogan 是一位从以色列情报部门走出来的连续创业者。他和联合创始人 Gil（前 NVIDIA 合成数据专家）正在构建一个"AI 控制平面"——用 AI agent 去监控其他 AI agent。

Maxim 的洞察非常深刻。他说，当你的 Claude Code 或 Coworker 拥有和你一样的权限时，传统的身份安全就失效了。端点和 API 安全工具也不知道 agent 在想什么、为什么要执行某个操作。所以你需要一个独立的安全层，专门理解 agent 的意图和行为。

最精彩的部分是他们的技术架构：他们不试图用一个强大的大模型去实时监控所有 agent 行为——那太贵也太慢了。相反，他们训练了非常小、非常专注的模型，这些模型几乎什么都不会，只会做一件事：判断"这个 action 是否需要让更聪明的 agent 来看一下？"这就像下快棋——大多数走法靠直觉，只有关键时刻才停下来深度计算。

Maxim 还分享了一个关键的市场洞察：企业不愿意把 agent 行为的历史数据给 Anthropic 或 OpenAI，因为知道这些公司会用数据来训练。但他们会给 Onyx，因为 Onyx 是一个独立的安全厂商，没有利益冲突。这个结构性优势让 Onyx 获得了大客户的信任。

https://www.youtube.com/watch?v=QDsbFLEt9ro

**The Takeaway:** As AI agents autonomously execute exponentially more actions inside enterprises, traditional security tools (identity, endpoint, API) have completely broken down — you need a specially trained small model as a "guardian" that only intervenes at critical moments, rather than using one large model to watch another.

Onyx Security CEO Maxim Bar Kogan, a serial entrepreneur from Israeli intelligence, is building an "AI control plane" — using AI agents to monitor other AI agents, alongside co-founder Gil (ex-NVIDIA synthetic data).

Maxim's insight is sharp. When your Claude Code or Coworker has the same permissions as you, traditional identity security is useless. Endpoint and API security tools have no idea what the agent is thinking or why it's performing an action. You need an independent security layer that specifically understands agent intent and behavior.

The best part is their technical architecture: they don't try to use one powerful large model to monitor all agent behavior in real-time — that's too expensive and slow. Instead, they train very small, focused models that can barely do anything except one thing: determine "does this action need a smarter agent to take a closer look?" It's like playing blitz chess — most moves are intuitive, and you only stop to calculate deeply at critical moments.

Maxim also shared a key market insight: enterprises won't give their agent behavior history to Anthropic or OpenAI because they know those companies will train on it. But they will give it to Onyx, an independent security vendor with no conflict of interest. This structural advantage gives Onyx trust from large customers.
